# Contributing

Node.js 24.21.0 LTS is required for this release. Run `npm ci`, `npm run typecheck`, `npm test`, `npm run lint`, and `npm run build` before a change. Use `npm run test:coverage` to inspect coverage when changing lifecycle or transport behavior. Tests use temporary SQLite files, an injected clock, a fake Telegram transport, and an injected HTTP fetcher; they must not require a bot token or contact Telegram. Include tests with two distinct client keys for changes to request access or idempotency. Add a numbered SQL migration for schema changes; do not edit a migration already used by a release. Keep the core lifecycle free of Telegram and HTTP types. Document changes to the public API and crash behavior. Please do not include credentials, request databases, or real message contents in issues or pull requests.
